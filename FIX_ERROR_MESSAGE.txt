"Token tidak valid atau sudah kadaluarsa"

Padahal belum ada token yang dikirim. Error ini berasal dari session lama.

## SOLUSI

✓ Clear semua old tokens dari database
✓ Clear Laravel cache (cache, view, config)
✓ System ready

Sekarang Anda perlu clear browser session:

═══════════════════════════════════════════════════════════════════════════

### STEP 1: CLEAR BROWSER COOKIES & SESSION

┌─────────────────────────────────────────────────────────────────────────┐
│ Di browser Chrome/Firefox/Edge:                                         │
│                                                                         │
│ 1. Tekan: Ctrl + Shift + Delete                                         │
│ 2. "Cookies and other site data" → Check                                │
│ 3. "Cached images and files" → Check                                    │
│ 4. Time range: "All time"                                               │
│ 5. Click: "Clear data"                                                  │
│                                                                         │
│ Atau langsung:                                                          │
│ - Tekan F12 (Developer Tools)                                           │
│ - Tab "Application" → "Cookies" → Select localhost:8000                 │
│ - Right-click → "Delete" semua                                          │
└─────────────────────────────────────────────────────────────────────────┘

### STEP 2: CLOSE & REOPEN BROWSER

Tutup semua tab, buka fresh browser window
